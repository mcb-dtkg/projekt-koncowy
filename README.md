# Katalog Oprogramowania

Projekt zaliczeniowy – prosta aplikacja webowa (Flask + SQLite) do katalogowania programów szkolnych.

## Funkcjonalności
- Dodawanie programów (nazwa, wersja, opis, kategoria)
- Wyszukiwanie programów
- Oznaczanie dostępności
- Trwałe przechowywanie danych (wolumen Dockera)

## Uruchomienie
Aby uruchomić projekt lokalnie, potrzebny jest Docker i Docker Compose.
